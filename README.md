# Swizell Pereira — Portfolio

Personal portfolio showcasing full-stack engineering work, interactive system design diagrams, and scalable architecture patterns. Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Stack

- Next.js 16 · TypeScript · Tailwind CSS v4 · Framer Motion

## Features

- Product-style portfolio (case studies, engineering principles, tech ecosystem)
- System Design Playground — 6 interactive SVG architecture diagrams
- Contact with LinkedIn, GitHub, and resume download

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Resume

Place your PDF at `public/resume.pdf` for the Download Resume button to work.

## Deploy

Deploy on [Vercel](https://vercel.com/new) or any Next.js-compatible host.
